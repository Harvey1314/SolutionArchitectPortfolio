# Harsh Patel — Solutions Architect portfolio

Static website ready for GitHub Pages. No build command or package installation is needed.

## Publish using GitHub Desktop on Mac

1. Open your existing Harsh_Patel repository in GitHub Desktop. If it is not listed, choose File > Clone Repository, select URL, and enter https://github.com/harvey1314/Harsh_Patel.git.
2. Choose Repository > Show in Finder.
3. Copy the contents of this folder into that repository folder. The index.html file must be directly in the repository folder. Replace matching website files; keep the existing .git folder and unrelated files.
4. In GitHub Desktop, review the changed files. Enter Update solutions architect portfolio in Summary, click Commit to your publishing branch, then Push origin.
5. On the GitHub website, open the repository's Settings > Pages. Set Source to Deploy from a branch, choose the branch you pushed (usually main) and /(root), then Save.
6. Wait for the GitHub Pages deployment to finish. Pages settings will show the published website URL.

GitHub Pages publishes the portfolio publicly. The private job tracker is not included.
